شیفت‌یار — راهنمای راه‌اندازی و تحویل نسخه ۱.۰
================================================

راه‌اندازی روی GitHub Pages (بدون بیلد یا نصب پکیج)
1. فایل ZIP را از حالت فشرده خارج کنید.
2. در GitHub یک مخزن بسازید. نام دلخواه، مثلاً shiftyar.
3. محتویات پوشه را در ریشه مخزن آپلود کنید؛ index.html باید در ریشه باشد.
4. در Settings > Pages، بخش Build and deployment را روی Deploy from a branch بگذارید.
5. شاخه main و پوشه / (root) را انتخاب و Save کنید.
6. پس از انتشار، آدرس نمایش‌داده‌شده در همان بخش را باز کنید.
7. HTTPS را فعال نگه دارید؛ نصب PWA و آفلاین به HTTPS نیاز دارد.

بستهٔ تحویل آماده اجراست و برای انتشار به بیلد، Node، سرور بک‌اند، API key یا CDN وابسته نیست.
فونت‌ها، تقویم، داده تعطیلات و کتابخانه‌های خروجی Excel و Word داخل خود پروژه قرار دارند.
فایل .nojekyll برای انتشار مستقیم فایل‌های استاتیک است.
هیچ مخزن GitHub برای شما ایجاد یا منتشر نشده؛ بسته آماده آپلود است.
نسخه اصلاح‌شده از app.bundle.js مستقل استفاده می‌کند؛ برای مشاهده محلی ابتدا ZIP را کامل استخراج و سپس index.html را باز کنید.
برای ذخیره‌سازی قابل اتکا و نصب PWA از GitHub Pages با HTTPS استفاده کنید؛ رفتار ذخیره‌سازی file:// میان مرورگرها متفاوت است.
اگر سایت قبلی را به‌روزرسانی می‌کنید همه فایل‌ها، از جمله boot.js، app.bundle.js و sw.js را جایگزین کنید؛ همه پنجره‌های سایت را ببندید و دوباره باز کنید تا کش جدید فعال شود.
اطلاعات سایت یا localStorage را برای رفع صفحه خالی پاک نکنید؛ داده شیفت‌ها در آن ذخیره است.
اگر بارگذاری ناقص باشد، به جای صفحه خالی پیام راهنما نمایش داده می‌شود.

شروع کار
- «حساب کاربری»: نام و عکس خود را تعیین کنید.
- «همکاران و داروخانه‌ها»: داروخانه را همراه نرخ هر ساعت به تومان ثبت کنید.
- قائم مقام‌ها را در ستون کناری اضافه کنید.
- «ثبت شیفت»: تاریخ شمسی، داروخانه، انجام‌دهنده، ساعت‌ها و یادداشت را ثبت کنید.
- «ماه نامه»: جدول هفته‌ای، انتخاب روز و جزئیات همان روز، ویرایش شیفت با انتخاب آن، بزرگنمایی، خلاصه و نمودار کارکرد.
- «گزارش کارکرد»: انتخاب شخص یا همه، ماه گزارش و ماه مقایسه، خلاصه و چهار نمودار.
- «برنامه ماه»: پرسنل، الگوهای شیفت، تخصیص افراد، ساعت اختصاصی، تکرار هفتگی و گزارش مستقل.

نصب روی آیفون
با Safari آدرس منتشرشده را باز کنید. Share > Add to Home Screen را انتخاب کنید.
بار اول برای دریافت فایل‌های آفلاین اتصال لازم است. پس از آن برنامه بدون اینترنت هم کار می‌کند.
در دسکتاپ و اندروید از گزینه نصب در منو یا نوار آدرس مرورگر استفاده کنید.

ذخیره‌سازی و حریم خصوصی
این نسخه تک‌دستگاهی و بدون ثبت‌نام آنلاین است. اطلاعات در localStorage همین مرورگر ذخیره می‌شود.
داده بین آیفون و دسکتاپ خودکار همگام نمی‌شود. برای انتقال، پشتیبان JSON بگیرید و در دستگاه دیگر بازیابی کنید.
از «حساب کاربری» به‌طور منظم پشتیبان بگیرید. بازیابی، کل داده قبلی را جایگزین می‌کند.
پاک کردن داده سایت، حالت خصوصی مرورگر یا حذف PWA می‌تواند داده‌ها را حذف کند.
فایل پشتیبان حاوی اطلاعات پرسنل و پرداخت است؛ آن را عمومی یا داخل مخزن GitHub قرار ندهید.
ذخیره‌سازی رمزگذاری‌شده یا ورود با رمز در این نسخه پیاده‌سازی نشده است.

قاعده‌های محاسبات
- همه تاریخ‌های داخلی میلادی ISO و ساعت‌ها به وقت تهران هستند؛ نمایش تاریخ شمسی است.
- پایان زودتر از شروع یعنی روز بعد؛ شروع و پایان یکسان یعنی ۲۴ ساعت.
- شیفت شخصی هم‌زمان برای یک فرد رد می‌شود؛ دو فرد متفاوت می‌توانند هم‌زمان کار کنند.
- نرخ زمان ثبت، روی شیفت ذخیره می‌شود و تغییر نرخ داروخانه مبلغ گذشته را تغییر نمی‌دهد.
- تغییر داروخانه هنگام ویرایش، نرخ داروخانه جدید را اعمال می‌کند.
- مرز ماه ساعت‌ها را تقسیم می‌کند؛ مثلاً شیفت ۲۲ تا ۶ آخر ماه، ۲ ساعت در ماه اول و ۶ ساعت در ماه بعد دارد.
- ماه نامه شیفت را در تاریخ شروع نشان می‌دهد؛ گزارش کارکرد، ساعت‌های واردشده از ماه قبل را هم حساب می‌کند.
- شیفت‌های آینده در جمع کارکرد و درآمد برنامه‌ریزی‌شده لحاظ می‌شوند؛ آینده با طلایی مشخص است.
- سبز برای شخص اصلی، بنفش برای قائم مقام و طلایی برای شیفت آینده، همراه برچسب متنی استفاده می‌شود.

برنامه مستقل پرسنل
- عادی ۰۶:۰۰ تا ۲۲:۰۰، شب ۲۲:۰۰ تا ۰۶:۰۰ است.
- تعطیل در کل روز اولویت دارد؛ ساعت تعطیل دوباره در شب یا عادی جمع نمی‌شود.
- عبور از نیمه‌شب و ماه به بخش‌های جداگانه شکسته می‌شود.
- تکرار یک تخصیص فقط همان روز هفته در همان ماه را شامل می‌شود.
- گزینه هفته‌های قبلی فقط همراه تکرار فعال می‌شود؛ جایگزینی موجودها نیازمند تأیید است.
- تخصیص هم‌زمان یک پرسنل به دو شیفت، حتی در عبور از نیمه‌شب، رد می‌شود.
- الگوهای پیش‌فرض سراسری هستند؛ تغییر ساعت الگو روی تخصیص‌های بدون ساعت اختصاصی ماه‌های قبلی هم اثر دارد و قبل از ذخیره هشدار داده می‌شود.
- مواردی که شیفت یا تخصیص مرتبط دارند، برای حفظ گزارش‌ها قابل حذف نیستند.
- اصلاح دستی تعطیلی فقط روی برنامه پرسنل اثر دارد، نه تقویم شخصی.

تقویم و تعطیلات
تبدیل تاریخ: jalaali-js 1.2.8.
تعطیلات: @jalali-js/holidays 0.4.2، داده ثابت شمسی و جدول تعطیلات قمری آفلاین.
بازه پیش‌فرض انتخاب: دو سال قبل تا دو سال بعد نسبت به تاریخ فعلی تهران.
تمام روزهای ۱۴۰۳ تا ۱۴۰۷ با تقویم فارسی استاندارد Intl تطبیق داده شده‌اند.
تعطیلات بسته از منبع ثانویه است؛ صحت تمام تعطیلات با سند رسمی مستقلاً تطبیق داده نشده است.
تعطیلات قمری آینده ممکن است با اعلام رسمی تغییر کند؛ پیش از محاسبه نهایی حقوق کنترل کنید.
در «برنامه ماه > تعریف تعطیلی» امکان تعطیل، روز کاری و بازگشت به تقویم وجود دارد.

خروجی‌ها
- XLSX واقعی: جدول فارسی راست‌به‌چپ؛ ماه نامه شامل شیت جدول هفته‌ای و شیت تمام جزئیات است.
- CSV سازگار با اکسل، همراه UTF-8 BOM و حفاظت در برابر فرمول‌های تزریق‌شده در متن.
- JSON گزارش برای پردازش؛ این فایل با پشتیبان کامل دستگاه فرق دارد.
- DOCX واقعی راست‌به‌چپ برای انتقال جدول به Word.
- HTML مستقل با جدول.
- PDF از مسیر چاپ مرورگر: در پنجره چاپ، Save as PDF را انتخاب کنید.
  در آیفون، از پیش‌نمایش چاپ و Share برای ذخیره PDF استفاده کنید.
  برای جدول ماه نامه، حالت افقی Landscape را انتخاب کنید.
  تولید PDF مستقیم بدون پنجره چاپ در این نسخه وجود ندارد.

توسعه و آزمون
Node.js 20 یا جدیدتر:
  npm ci --ignore-scripts
  npm run bundle
  npm test
  npm run check
بعد از تغییر سورس، npm run bundle را اجرا کنید و app.bundle.js تولیدشده را هم منتشر کنید.
پکیج‌ها فقط برای توسعه/تست هستند؛ پوشه node_modules را در GitHub آپلود نکنید.
تست‌ها شامل تبدیل تاریخ پنج‌ساله، محاسبات شب و تعطیل، مرز ماه، تکرار، تداخل، ذخیره فرم‌ها، خروجی Excel و Word و Service Worker هستند.
تست DOM با linkedom انجام می‌شود، نه مرورگر واقعی.
بررسی بصری واقعی دسکتاپ/آیفون، نصب واقعی PWA و پنجره چاپ PDF در این محیط انجام نشده‌اند.
پیش از استفاده عملی، نصب، چاپ و نمایش موبایل را روی دستگاه خود آزمایش کنید.

فایل‌ها
index.html: ورودی فارسی و متادیتای PWA
app.js: سورس رابط و گردش عملیات
app.bundle.js: ورودی مستقل و آماده اجرا، بدون import زمان اجرا
boot.js: نمایش خطای بارگذاری به جای صفحه خالی
styles.css: پالت واحد سرمه‌ای/طلایی، RTL، موبایل و چاپ
core.js: تاریخ، محاسبات، گزارش، اعتبارسنجی
spreadsheet.js: تولید Excel و Word آفلاین
sw.js: کش آفلاین؛ در هر انتشار مقدار CACHE را نسخه‌گذاری کنید
manifest.webmanifest: تنظیمات نصب
assets/: فونت و آیکون‌ها
vendor/: کتابخانه‌های آفلاین و مجوزهای آن‌ها
tests/: آزمون‌های خودکار
package.json و package-lock.json: محیط توسعه قابل تکرار

مجوزهای اجزای شخص ثالث در assets و vendor همراه پروژه قرار دارند.
